# ChainPurge

ChainPurge leverages real-time data processing and event-driven architecture to optimize blockchain operations, accelerating processor performance and engine efficiency.

ChainPurge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainPurge.git`
2. `cd ChainPurge`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
